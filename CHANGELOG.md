# Changelog

This project follows semantic versioning for the HDP contract after 0.1.
Pre-1.0 drafts may make incompatible changes with explicit migration notes.

## 0.1.0-draft — 2026-08-20

- Introduced the implementation-neutral HDP conceptual model.
- Added the canonical JSON Schema, ontology, and semantic-rule catalogue.
- Added provider-neutral templates and worked examples.
- Added portable `create-hdp` and `analyse-existing-harness` Agent Skills.
- Separated the draft specification from the non-normative Harness Factory
  implementation.
