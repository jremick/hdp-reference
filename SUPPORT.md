# Support

HDP Draft 0.1 is an experimental, maintainer-led specification. There is no
service-level commitment or production support contract.

Use GitHub Issues for reproducible specification defects, ambiguities, missing
use cases, examples, or compatibility questions. Include the affected contract
version and the smallest non-sensitive example that demonstrates the problem.

Use GitHub's private vulnerability reporting flow for security issues or unsafe
guidance. Do not place credentials, private harness content, hidden evaluator
material, or exploit details in a public issue. See [SECURITY.md](SECURITY.md).
