# Roadmap

## Draft 0.1 review

- Validate the field model across software development, knowledge work,
  operations, research, and human-in-the-loop workflows.
- Stabilize the semantic-rule expression and diagnostic identifiers.
- Add more provider-neutral conformance vectors and reconstruction examples.
- Test the portable Agent Skills across multiple compatible agent platforms.

## Draft 0.2

- Define a modular authoring package and deterministic resolution rules.
- Define machine-readable profile declarations and compatibility claims.
- Publish adapter mapping guidance for selected interoperability formats.
- Add implementation conformance reports without creating a certification
  claim.

## Toward 1.0

- Establish a transparent proposal and decision process.
- Resolve ownership and long-term governance of identifiers and schemas.
- Demonstrate independent implementations and round-trip compatibility.
- Complete security, privacy, accessibility, and internationalization review.
